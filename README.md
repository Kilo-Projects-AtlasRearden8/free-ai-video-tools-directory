# Free AI Video Tools Directory

A freebies directory of free and free-tier AI video tools for editing, captioning, thumbnails, and enhancement. Each listing includes cost, platform, beginner steps, and the official link. No affiliate links — every link goes to the tool's own website.

## What's inside

- `index.html` — static site with client-side search (open it directly in any browser, or serve with any static file server; no build step)
- `tools.json` — structured data behind the site (16 tools across editing, captioning, thumbnails, enhancement)
- `tools.md` — Markdown version of all listings with step-by-step beginner guides
- `LICENSE` — MIT License
- `STATUS.md` — what was built, how to run it, verification results, known gaps

## How to run

Open `index.html` in your browser. The search and category filters run entirely in your browser — nothing is uploaded or tracked.

Optionally serve it locally:

```bash
python3 -m http.server
# then open http://localhost:8000
```

## Data

Every listing shows: tool name, category, cost, platform, steps, and official link. Costs and free-tier terms change over time — check each official site before relying on a free tier.
